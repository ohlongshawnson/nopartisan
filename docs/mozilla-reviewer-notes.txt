NOpartisan 0.3.0 (Firefox ID: nopartisan@ohlongshawnson.github.io)

Purpose: Hide social-feed items that match local, literal political keyword phrases, regardless of party or viewpoint. Supported sites are Reddit, X, and Facebook. The complete schema-1 list is bundled, so filtering works immediately and offline. Personal keywords, global filtering, placeholders, and Reveal controls remain local.

Permissions: `storage` stores settings and the validated downloaded list; `alarms` schedules optional daily list downloads while Firefox is running; `menus` provides a user-initiated X post diagnostic. Required website access is limited to www.reddit.com, x.com, and www.facebook.com for feed filtering. Optional access to raw.githubusercontent.com is requested only after the user chooses “Update filters now” or enables daily updates. The maintained list is fetched from https://raw.githubusercontent.com/ohlongshawnson/nopartisan/main/keywords/politics.json. GitHub can see ordinary connection data such as the user's IP address and requested URL. Feed content, browsing history, personal keywords, and matched phrases are never sent. Downloads omit credentials and referrers, are limited to 1 MB, and validate schema 1 before storage. Failures preserve the prior valid list.

Testing: Install and open a supported feed to verify the bundled offline behavior. In the toolbar settings, confirm the active list version and count. Choose “Update filters now” to exercise the optional permission prompt; declining leaves filtering enabled with the current list. To test daily checks, enable the checkbox while granting GitHub access. Synthetic fixtures and automated tests cover list validation, update failure recovery, migration of existing settings, storage-driven rescanning of open tabs, and keyword-file synchronization. Authenticated social-account credentials are not needed or provided.

The X “Why is this post visible?” report is opened only by an explicit user action. Its selected post text stays in extension messaging/session memory and is rendered locally as text; it is not uploaded or written to routine logs. The extension does not perform OCR or semantic classification. No third-party runtime libraries are included.

Runtime source is shipped as readable JavaScript, HTML, CSS, JSON, and PNG. No bundling, transpilation, minification, or code generation is used. The reproducible ZIP is built from the repository with Python 3 using `python3 tools/package.py`; run `npm ci`, `npm test`, `npm run lint`, and `npm run check:release` for source and release checks. The upload archive contains only reviewed extension runtime assets and the MIT license.
