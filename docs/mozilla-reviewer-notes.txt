NOpartisan 0.3.1 (Firefox ID: nopartisan@ohlongshawnson.github.io)

Purpose: Automatically hide political social-feed items using permanent political vocabulary, a bundled list and explicit X Politics trend-category detection. Supports Reddit, X and Facebook. Filtering starts offline; personal keywords, preferences, placeholders and Reveal stay local.

New-install update behavior: A genuinely fresh install saves autoUpdate:true and immediately starts an asynchronous download of https://raw.githubusercontent.com/ohlongshawnson/nopartisan/main/keywords/politics.json. Content scripts initialize from packaged resources independently. Downloads omit credentials and referrers, reject redirects, cap the body at 1 MB and validate schema 1. Validated downloaded phrases are merged with packaged foundational vocabulary and published with metadata in one storage transaction. Existing tabs rescan via storage.onChanged. Successful downloads schedule the next check in 24 hours; failures retain the last valid filters and schedule a one-hour retry. Startup restores the saved due time and catches up if overdue.

Permissions: storage for preferences/cache/status; alarms for checks; menus for local inspection. Required host permissions are HTTPS www.reddit.com, x.com and www.facebook.com for filtering, plus https://raw.githubusercontent.com/* for keyword downloads. Firefox host grants are effectively host-wide; the application accepts the exact maintained URL for new configuration. Existing saved custom HTTPS raw.githubusercontent.com paths within nopartisan repositories remain supported for compatibility. No arbitrary website, telemetry or remote executable code is requested. Existing opted-out or unset legacy update preferences are not enabled by upgrade. A user may revoke host access; local filters continue to work. A manual settings action can request regranting a revoked update host.

Privacy: GitHub sees normal connection metadata, including IP address and requested file URL. No feed text, browsing history, personal phrases, matched phrases, identifiers, telemetry or analytics are included in requests. The manifest declares no collected data; the HTTP request is solely for the public filter data. Listing/settings/privacy copy disclose automatic downloads and how to disable them. Local diagnostics are invoked by the context menu, passed through extension messages/session memory and rendered locally. Reports are not uploaded or added to routine logs.

Validation: Node and Python tests cover offline defaults, vocabulary persistence, upgrade preferences, URL restrictions, invalid/empty/oversize responses and stale/concurrent requests. Firefox 160 performs real TLS downloads to the maintained GitHub endpoint; an encrypted CONNECT tunnel delays the request to prove bundled filtering starts first. Actual permission revocation, connection failures, recovery and storage-driven rescanning pass. Firefox Developer Edition 161 uses disposable profiles with unsigned test installation enabled solely to test persistent candidate install/restart and scheduled-time recovery. Local fixtures cover Politics/Alito, neutral Gaming/News trends and existing adapters. Authenticated live X remains a tester-owned account check, not an agent-observed claim.

Source is readable JS/HTML/CSS/JSON/PNG, with no transpilation/minification or runtime dependencies. Run npm ci, npm test, npm run lint, npm run build and npm run check:release. The archive contains only reviewed runtime assets and LICENSE. No production server, collector schedule or service changes are included. This is a local unsigned candidate; submission to the existing AMO listing is not automated.
