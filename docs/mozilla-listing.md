# Mozilla Add-ons listing copy

## Name

NOpartisan

## Summary

Filter political content from social feeds, with no left and no right. NOpartisan works offline with a complete bundled keyword list; optional GitHub updates keep it current.

## Description

NOpartisan filters supported Reddit, X, and Facebook feed items using local whole-word and phrase matching. It treats political viewpoints alike and gives you control over personal keywords, placeholders, and global filtering.

Filtering is ready immediately after installation. The complete keyword list ships with the extension, so it works offline without an account, URL setup, or network permission. You can choose **Update filters now** or enable daily updates while Firefox runs. GitHub access is optional and requested only after that action. If you decline, the bundled or last valid list continues to work.

Feed text, browsing history, personal keywords, and matched phrases stay in Firefox and are never sent to NOpartisan or GitHub. When you download a list, GitHub can see ordinary connection information such as your IP address and requested URL. Failed or invalid downloads leave the last valid list in place.

NOpartisan reads text and available accessible descriptions. It does not use OCR or classify political meaning. Political names and phrases may be missed, and broad terms can hide unrelated posts. Filtering can be paused or reversed, and placeholders can include a Reveal control.

## Version note

The bundled list is the schema-1 snapshot in `keywords/politics.json`; the Firefox archive carries the identical `extension/keywords.json` file. Maintained data updates do not replace the signed extension binary.
