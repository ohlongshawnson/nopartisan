# NOpartisan 0.3.0 — first unlisted Firefox test release

NOpartisan filters supported Reddit, X, and Facebook feeds immediately with the complete bundled political list. Updates are optional and use GitHub only after a user chooses **Update filters now** or enables daily checks.

- Bundles 869 unique schema-1 keywords, version `2026-11-05.537802fbba04`, from published commit `3379294f7d1210671bc51241c16d968ca8293221`. The canonical and extension JSON files are byte-identical.
- Adds a simple maintained update control, active list version/count, last successful download, and update failure status.
- Requests optional `raw.githubusercontent.com` access only after a user action. The full bundled list and last valid downloaded list work offline.
- Preserves personal keywords, filtering preferences, existing custom update sources, cached lists, and explicit automatic-update opt-outs.
- Includes the tested collector and publishing implementation/configuration. Repository configuration targets `main` and synchronizes both keyword files. Live OMV deployment state was not inspected from the workstation; no schedule or server deployment was changed.
- Retains whole-phrase matching, custom keywords, quick toggles, placeholders, and the local X post-inspection tool.

The extension version is **0.3.0**. Permanent Firefox ID remains `nopartisan@ohlongshawnson.github.io`. Keep this ID and increment the version for later releases. Runtime source remains readable; no bundling, transpilation, or minification is performed. Development dependencies and automation server files are not in the upload ZIP.

Privacy: feed content, browsing history, personal keywords, and matched phrases are not transmitted. GitHub sees ordinary network connection information such as the user's IP address and requested list URL when a list download is requested. No download is required for filtering.

This is an unsigned unlisted Mozilla submission package. Submit it through Mozilla's self-distribution route to obtain the signed XPI; do not install or distribute the unsigned ZIP as a release.

Validation: 35 JavaScript tests and 46 collector/publisher Python tests passed. The 19 political and 14 nonpolitical matcher cases passed against the bundled list. `web-ext lint` reported zero errors, notices, or warnings. The reproducible package and release guard passed, and the exact ZIP temporarily installed in an isolated Firefox 159 profile with the expected ID, version, ready bundled list, and no GitHub permission on install. Optional-permission and update recovery checks were automated fixtures; authenticated live social feeds and the OMV deployment were not inspected in this release task.
