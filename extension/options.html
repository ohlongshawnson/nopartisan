Set up political filtering

A keyword list is included with the extension; no download or GitHub access is needed to use it. Filtering matches listed words and phrases, so political posts with no matching phrase can remain visible. Add missing phrases to your personal keywords. Feed text and your personal keywords stay on this device.

Website access

Firefox must allow NOpartisan to read and change each supported website before it can filter there. Grant access below, then refresh any already-open tabs. You can revoke access in Firefox's add-on permissions. This access is separate from optional GitHub downloads.

Filtering

Turn placeholders off to hide matching posts and trends completely. Hidden content will have no Reveal button.

Matches whole words and phrases, regardless of case. Broad terms can hide unrelated posts.

Filter list updates

Optional downloads bring the latest reviewed list from GitHub. GitHub receives ordinary connection details, such as your IP address, when you download. Feed content and personal keywords are never sent.

When enabled, Firefox checks daily while it is running. Save settings to approve optional GitHub access.

Advanced update source

The maintained NOpartisan list is used by default. Change this only if you maintain another list in the supported schema. Leave blank to restore the default source.

Initial support: Reddit, X, and Facebook web feeds. Text only; images, video, and changing site layouts can limit coverage.
