Automatic political filtering

NOpartisan includes a permanent political vocabulary and filters X trends explicitly categorized as Politics. No personal keywords, download or GitHub access are needed for these default filters. Optional extra phrases can extend coverage. Feed text and your personal keywords stay on this device.

Website access

Firefox must allow NOpartisan to read and change each supported website before it can filter there. Grant access below, then refresh any already-open tabs. You can revoke access in Firefox's add-on permissions. Update-service access is separate from these feed websites.

Filtering

Turn placeholders off to hide matching posts and trends completely. Hidden content will have no Reveal button.

Matches whole words and phrases, regardless of case. Broad terms can hide unrelated posts.

Filter list updates

New installations automatically get updated political keywords from GitHub after installation and every 24 hours while Firefox is running. GitHub receives ordinary connection details, including your IP address and the requested file address. Feed content and personal keywords are never sent. Turn automatic updates off below at any time; local filtering will continue.

Included filters work immediately and offline. Failed downloads keep your current filters and retry later. Existing update preferences are preserved.

Advanced update source

The maintained NOpartisan list is used by default. Existing custom sources are preserved. Newly configured sources must use the maintained list. Leave blank to restore the default source.

Initial support: Reddit, X, and Facebook web feeds. Text only; images, video, and changing site layouts can limit coverage.
